## Setup steps

1. Create pass template at app.epasscard.com  
2. Install EpassCard plugin and connect API key  
3. Enable WooCommerce Subscriptions module  
4. Map each subscription product to a template  
5. Optionally enable order email pass links  
6. Test with a subscription order
