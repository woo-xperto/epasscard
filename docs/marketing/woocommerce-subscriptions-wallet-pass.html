Turn WooCommerce subscriptions into wallet passes

Subscription businesses on WooCommerce often rely on email receipts and login credentials. Subscribers forget renewal dates, lose access details, and never feel a tangible connection to your brand.

EpassCard connects WooCommerce Subscriptions to Apple Wallet and Google Wallet. Map each subscription product to a pass template — passes issue per subscription record and update when data changes.

How to set up WooCommerce Subscriptions wallet passes

  1. Create a pass template in your EpassCard account.
  2. Install EpassCard and connect under EpassCard → Connection.
  3. Enable WooCommerce Subscriptions on the Connection page.
  4. Open EpassCard → WooCommerce Subscriptions and map each subscription product to a template.
  5. Optionally enable Include pass links in WooCommerce order emails on the Connection page.
  6. Place a test subscription order and confirm the pass in admin and My Account.
Subscriber experience

After checkout, the customer can add their pass from the order email, from My Account → Wallet passes, or from an automatic pass-link email when a new pass is created.

Use cases for subscription wallet passes

  • Membership boxes — subscriber tier and renewal date on the lock screen
  • SaaS with WooCommerce billing — plan name and status in Google Wallet / Apple Wallet
  • Content subscriptions — branded pass as subscriber identity
  • Local delivery clubs — subscription ID and next billing date for support
  • Annual renewals — push reminders before renewal (WCS timing)

Frequently asked questions

Does WooCommerce Subscriptions support wallet passes out of the box?

No. EpassCard adds Apple Wallet and Google Wallet pass issuance for subscription products.

One pass per customer or per subscription?

Per subscription record. A customer with multiple active subscriptions can have multiple passes.

Can pass links appear in order emails?

Yes. Enable Include pass links in WooCommerce order emails on the Connection page.

What happens when a subscription is cancelled?

Passes may be marked revoked locally and hidden from the frontend pass list per integration rules.

Does this work with MemberPress too?

Yes. EpassCard supports MemberPress, WooCommerce Subscriptions, and Ultimate Membership Pro as separate modules. MemberPress guide →
