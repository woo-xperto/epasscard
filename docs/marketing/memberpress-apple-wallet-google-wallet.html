How to add a membership card to Apple Wallet on WordPress

Setup takes about 15 minutes. No code required.

  1. Create a pass template in your EpassCard account — logo, colors, and fields.
  2. Install EpassCard on WordPress and connect your API key under EpassCard → Connection.
  3. Enable the MemberPress module on the Connection page and save.
  4. Map each membership product under EpassCard → MemberPress — choose a template and map fields.
  5. Done. When a member completes signup, EpassCard creates their wallet pass and can email the add-to-wallet link.
After signup

EpassCard calls the API with mapped member data, stores the pass link in WordPress, shows it in Issued passes, and lets members access it from the Wallet Passes tab in their MemberPress account.

Frequently asked questions

Does MemberPress have a built-in Apple Wallet integration?

No. EpassCard is a dedicated WordPress plugin that adds Apple Wallet and Google Wallet passes to MemberPress memberships.

Do members need to install an app?

No. Members add the pass through a standard Add to Apple Wallet or Save to Google Wallet link.

Can I use different pass designs per membership level?

Yes. Map each MemberPress membership product to its own EpassCard template.

Are passes updated when a member renews?

Yes. EpassCard issues on renewal and updates passes when mapped fields change.
