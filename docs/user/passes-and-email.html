Passes & email

Issue wallet passes and deliver pass links by email, order notifications, or member self-service.

Issued passes list

Each integration shows record ID, member, plan, pass ID, link, status, and actions: Create, Update, Email pass link.

Automatic pass creation

  1. Collect source field values from the membership record
  2. Call the EpassCard API to create or update the pass
  3. Store pass_uid and pass_link locally

Email delivery channels

Automatic

Enable on Connection — sent when a new pass is created.

Manual (admin)

Click Email pass link on Issued passes or member lists.

WooCommerce orders

Pass links appended to customer order emails when enabled.

Member self-service

  • WooCommerce My Account → Wallet passes
  • MemberPress Wallet Passes account tab
  • Shortcode [epc_my_passes]

See My Account & shortcode for details.

Troubleshooting email

  • Confirm wp_mail works (try an SMTP plugin)
  • Member must have a valid user email
  • Pass must exist with a pass_link
