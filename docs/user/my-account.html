My Account & shortcode

Let members access wallet passes without opening email links.

WooCommerce My Account

Menu item Wallet passes at /my-account/wallet-passes/. Requires active passes for the logged-in customer.

404 fix

After install, visit Settings → Permalinks and save once if the endpoint 404s.

MemberPress account

Wallet Passes nav links to ?action=wallet_passes on the account page.

Shortcode

Shortcode
[epc_my_passes]

Logged-out users see a login prompt. Logged-in users see buttons linking to active passes.

Pass list behavior

  • Only active passes with a pass_link
  • Labels include membership/product name when available
  • Links open in a new tab

Developers: see Frontend hooks.
