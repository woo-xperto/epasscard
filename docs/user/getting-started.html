Getting started

Install EpassCard, connect to your account, and start issuing wallet passes for memberships and subscriptions.

Requirements

  • WordPress 6.5+
  • PHP 8.1+
  • An EpassCard account with at least one pass template
  • One supported plugin: MemberPress, WooCommerce Subscriptions, or Ultimate Membership Pro

Installation

  1. Upload the epasscard folder to wp-content/plugins/.
  2. Activate EpassCard under Plugins.
  3. Open EpassCard → Connection in the WordPress admin.

Basic setup

  1. Connect — Paste your API key or sign in with EpassCard credentials.
  2. Enable integrations — Check the plugins you use and save.
  3. Open an integration — e.g. EpassCard → MemberPress.
  4. Map templates — Choose a pass template and map fields per plan.
  5. Issue passes — Automatic on subscribe, or manual via Create pass.
Smartest card solution

Like EpassCard itself, this plugin bridges your brand and customers with dynamic digital passes for Apple and Google Wallet — no plastic required.

What happens after setup

  • Qualifying members get a wallet pass via the API; the link is stored locally.
  • Profile changes can update existing passes automatically.
  • Optional reminder pushes use your membership plugin’s native timing.
  • Pass links can be emailed, included in order emails, or viewed in My Account.
